# M4zk1pL4y Cinema

Android WebView shell for the UI with a dedicated native Android video player powered by AndroidX Media3 (ExoPlayer). Browser playback remains available for the hosted web version.

## Android playback
- APK playback uses ExoPlayer for progressive MP4 and HLS streams.
- WebView is used for the app UI and API orchestration only.
- Playback progress, episode completion, resume position and quality selection are bridged between JavaScript and Android.

## Build and download
Every push to `main` runs **Build APK**. The workflow uploads:
- `M4zk1pL4yCinema-apk` as a GitHub Actions artifact.
- A public GitHub Release containing `app-debug.apk`.

Manual build: `gradle :app:assembleDebug`.

## Project layout
- `index.html`: web UI and API client.
- `app/src/main/assets/index.html`: generated by the workflow from the root HTML file.
- `app/src/main/kotlin/com/mazkiplay/cinema/`: Android activities and JavaScript bridge.
- `app/src/main/res/`: Android resources used by the APK.
- `tools/make-icons.sh`: generates launcher icon density assets from `kiplay.png`.
